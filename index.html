Installs the panels and connects your assistants.

Settings

What setting everything up changes on your Mac:

  • Copies the MCP panels into ~/Library/Application Support/Adobe/CEP/extensions
  • Turns on Adobe's PlayerDebugMode, a global Adobe preference, so unsigned panels are allowed to load
  • Adds this app's servers to Claude Desktop, Claude Code and Codex config files — a timestamped backup of each is kept beside it
  • Downloads a small Python runtime on first run
  • It never touches your documents
