What can I do with this?

Ask Claude or ChatGPT in your own words. You never name a command — describe what you want in the document you have open, the way you would to a colleague looking over your shoulder.

Say which app you mean if it could be either. “Export a PNG” could be Illustrator or After Effects, and the assistant will ask. Naming it saves a round trip.

Illustrator

Illustrator

The most complete of the four. It can read your document and change it.

  • Read — what is on each artboard, what you have selected, layers, swatches, fonts
  • Draw — rectangles, ellipses, lines, text, placed images, artboards, layers
  • Change — colour, position, size, rotation, opacity, alignment, spacing, grouping, type and font
  • Export — PNG at any scale, SVG, or save a copy
  • Fetch — download an image from a link, save it next to your file, and place it
Try saying
Make a 1200×630 artboard and centre the logo on it Everything on this artboard that is orange, change it to #2855ff Space these six icons evenly across the artboard Set the headline in Inter Semibold at 48pt and tighten the tracking Export this artboard as a PNG at 2× onto my desktop
It cannot

Pathfinder, Offset Path, Outline Stroke, the whole Effect menu (drop shadows, warps, blurs) and the Appearance panel. Adobe gives these no scripting access at all, so nothing built on scripting can reach them — ours included. The assistant will say so rather than produce something that only looks right. Image Trace does work.

After Effects

After Effects

Built around effects, because that is what After Effects gives scripts access to. It reads the effects installed on your machine, so Video Copilot, Red Giant and Boris FX work the same as Adobe’s own.

  • Read — compositions, layers, and what is already applied to a layer
  • Apply — any installed effect, including third-party plugins
  • Adjust — set any parameter on an applied effect
  • Animate — keyframe an effect parameter or a transform, with easing
  • Presets — apply an .ffx animation preset
Try saying
What effects do I have installed with “glow” in the name? Put a Gaussian Blur on the logo layer and take it from 40 to 0 over the first second Fade this layer up over 12 frames with an ease out What is already applied to the background layer?
It cannot

Roto Brush, Content-Aware Fill and mask tracking. It also cannot read rendered pixels, so it cannot tell you how something looks — only what is set.

Photoshop and Premiere Pro

Photoshop

Layers, selections, masks, adjustments and export.

  • Layers — create, duplicate, group, rename, move, scale, rotate, flip
  • Selections — rectangle, ellipse, polygon, subject, sky; turn one into a mask
  • Adjustments — brightness and contrast, colour balance, vibrance, black and white
  • Styles — drop shadow, stroke, gradient
  • Generate — make an image from a description with Adobe Firefly, on its own layer
  • Generative fill — describe what should go inside a selection and let it blend in
  • Clean up — remove a background, harmonise a pasted layer with the scene
  • Export — PNG of the document or of single layers
Try saying
Select the subject, mask it, and drop the background out Generate a soft grey studio backdrop on a new layer behind the product Select the sky, then fill it with an overcast sky at dusk Export each layer as its own PNG

Premiere Pro

Projects, bins, sequences and the basics of cutting.

  • Project — create, open, save, import media, organise into bins
  • Sequences — build one from clips, add markers, close gaps
  • Clips — set in and out points, disable, change position and scale
  • Effects — Gaussian blur, motion blur, tint, black and white, transitions
  • Export — a frame, or the whole sequence
Try saying
Import everything in this folder and put it in a bin called Rushes Build a sequence from these clips in order and close the gaps Add a cross dissolve between every clip

Using two apps together

Make an image in Photoshop, use it in Illustrator

Photoshop can generate images with Firefly. Illustrator cannot, but it can place a file. So the route between them is a saved PNG.

Ask Photoshop
Generate a hand-drawn palm leaf on a white background and save it as a PNG on my desktop
Then ask Illustrator
Place that PNG on the artboard and scale it to 400px wide
If the image is a link

Ask Illustrator to fetch it. It saves the file next to your document — or in a subfolder you name — and can place it in the same step. It only accepts web links, and never overwrites a file you already have.

Worth knowing

It works on the document you have open. There is no separate copy and nothing is uploaded. Changes land in the file in front of you.
You can undo it. Everything the assistant changes in After Effects is grouped into a single undo. In the others, undo works as it normally does.
Not while something is rendering. Adobe blocks scripting during a render, so wait for it to finish.
When there is no tool for something, the assistant can still write Illustrator or After Effects scripting directly. That covers gradients, blends and unusual path work. It is slower and likelier to need a second attempt, so it is a fallback, not the usual route.
