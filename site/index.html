A web page can't install panels into your Adobe apps or reach anything on your Mac — browsers block that on purpose. So there's one download, and after that one button does the rest.

  1. Open the download and drag the app onto Applications. Both are in the window that opens. Run it from Applications, not from the disk image — it can't set itself up or update from there. No Node, no Python, no terminal; the first run downloads a small Python runtime, so it needs the internet once.
  2. Double-click it. macOS will refuse the first time — that's expected. Go to System Settings → Privacy & Security, scroll down and click Open Anyway next to Moskito Easy MCP. Only needed once.
    (Right-click → Open stopped working in macOS 15. The app isn't signed by Apple, which costs €99/year.)
  3. Press “Set everything up”. It installs the panels and connects Claude and ChatGPT. macOS asks to allow Accessibility — that's for arranging your windows side by side.
    • Photoshop, Premiere and InDesign also need Adobe's free UXP Developer Tool. If it's missing, setup opens Adobe's download page — install it and press Set up again. Open them after the Developer Tool is running: they only connect to it when they start.
    • Photoshop only: turn on Photoshop → Settings → Plugins → Enable Developer Mode once.
  4. Restart Claude and ChatGPT. They only pick up new tools when they start. The app shows a Restart assistants button for this.

Switch off any Adobe app you don't use, with the tick next to it in the app. Each one takes up space in every message your assistant sends.

ChatGPT works in its desktop app and Codex, not in a browser tab — a browser can't reach an app on your Mac. Codex may need one Allow click in Moskito Easy MCP, because it switches networking off for tools by default.

  1. Open the Moskito Easy MCP panel in your Adobe app and leave it open. The panel is the connection — close it and nothing reaches the app. In Illustrator and After Effects it opens by itself when the app starts.
    • Illustrator, After Effects — Window → Extensions → Moskito Easy MCP
    • Photoshop — Plugins → Moskito Easy MCP
    • Premiere Pro — Window → UXP Plugins → Moskito Easy MCP
    • InDesign — Plug-Ins → Moskito Easy MCP → Moskito Easy MCP
  2. Open Claude or ChatGPT. The desktop apps — Claude's Code tab works too — not a browser tab. The panel has buttons for both.
  3. Say what you want, in plain words. It works inside the document you have open, and your Mac stays yours to use while it does. The panel's log shows each step as it arrives.

Things people ask for:

Make me a 1080×1920 story with a bold headline in our brand colours.

Rename every layer in this file to a consistent format.

Raise the exposure on the second clip and fade it in over a second.

Create a 5 second comp and fade the title in.

Save before you start. It edits the document you have open, and not every step can be undone. Try it on a copy first.

It keeps itself up to date: new versions download quietly, and it asks before restarting. After an update, reopen Photoshop, Premiere or InDesign so their panel picks it up.
