Install

A web page can't install panels into Illustrator or reach the apps on your Mac — browsers block that on purpose. So there's one download. After that, one button does the rest.

  1. Download and drag to Applications. No Node, no Python, no terminal. It's all inside the app.
  2. Right-click → Open. Only the first time — macOS asks this of any app not from the App Store.
  3. Press “Set everything up”. It installs the panels and connects Claude and ChatGPT for you.

What's automatic

Illustrator, After Effects Fully automatic. Panel installed and connected for you.
Photoshop, Premiere, InDesign One extra click. Adobe only auto-installs plugins it has signed, so these load through Adobe's free UXP Developer Tool — you press Load once.
Claude Desktop, Claude Code Connected automatically.
ChatGPT desktop, Codex CLI Connected automatically. They share one config file. ChatGPT in a browser tab can't reach an app on your Mac — its connectors only see the public internet.
