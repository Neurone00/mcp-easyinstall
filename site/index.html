Install

A web page can't install panels into Illustrator or reach the apps on your Mac — browsers block that on purpose. So there's one download. After that, one button does the rest.

  1. Download and drag to Applications. No Node, no Python, no terminal. First run downloads a small Python runtime, so it needs the internet once.
  2. Double-click it. macOS will refuse the first time — that's expected. Then go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to Moskito Easy MCP. Only needed once.
    (Right-click → Open no longer works: Apple removed that shortcut in macOS 15. The app isn't signed by Apple, which costs €99/year.)
  3. Press “Set everything up”. It installs the panels and connects Claude and ChatGPT for you.

How to use it

  1. Open the MCP panel in your Adobe app and leave it open. That panel is the connection — close it and nothing works.
    • Illustrator, After Effects — Window → Extensions → MCP Agent
    • Photoshop — Plugins → MCP Agent
    • Premiere Pro — Window → MCP Agent
  2. Open Claude or ChatGPT. The desktop apps, not a browser tab. There are buttons for both right inside the panel.
  3. Say what you want, in plain words. It works on the document you already have open. Watch the panel's message log to see each step arrive.

Things people ask for:

Make me a 1080×1920 story with a bold headline in our brand colours.

Rename every layer in this file to a consistent format.

Build a rough cut from these clips with cross dissolves between them.

Create a 5 second comp and fade the title in.

Save before you start. It edits the document you have open, and not every step can be undone. Try it on a copy first.

What's automatic

Illustrator, After Effects Fully automatic. Panel installed and connected for you.
Photoshop, Premiere One extra click. Adobe only auto-installs plugins it has signed, so these load through Adobe's free UXP Developer Tool — you press Load once.
Staying up to date Automatic. The app offers a one-click update when there's a new version, and the Adobe panels refresh themselves every launch.
Claude Desktop, Claude Code Connected automatically.
ChatGPT desktop, Codex CLI Connected automatically. They share one config file. ChatGPT in a browser tab can't reach an app on your Mac — its connectors only see the public internet. These tools live in ChatGPT's Codex surface, and need one Allow click in Moskito Easy MCP — Codex sandboxes MCP servers with networking off.
